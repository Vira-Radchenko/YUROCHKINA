# YUROCHKINA — сайт-портфоліо Віри Радченко

Багатосторінковий сайт на чистих HTML, CSS і JavaScript. Без збірки й без сервера — працює на GitHub Pages.

## Структура

```
veexy-portfolio/
├── index.html          головна (надувний заголовок, послуги, роботи)
├── portfolio.html      усі проєкти + фільтр
├── services.html       послуги, ціни, калькулятор і замовлення
├── about.html          про мене, освіта, навички
├── contacts.html       контакти, форма заявки, FAQ
├── 404.html            сторінка «не знайдено»
├── en/ ru/ pl/ de/ lt/  інші мови: у кожній папці ті самі 6 сторінок + cases/ (5 кейсів)
├── cases/              окрема сторінка для кожного кейсу
│   ├── delintra.html  dezlife.html  handesi.html  harmonia.html  vilno.html
├── css/style.css       усі стилі (кольори — на початку файлу, в :root)
├── css/lang.css        стиль перемикача мови (випадаюче меню UA · EN · RU · PL · DE · LT)
├── js/config.js        ⭐ ВАШІ ДАНІ: email, месенджери, соцмережі, ЦІНИ
├── js/main.js          бургер-меню, калькулятор, форма, анімації
└── images/
    ├── about/portrait.jpg              ваше фото
    ├── icons/                          іконки соцмереж
    └── projects/<проєкт>/cover.jpg     обкладинка
                         01.jpg … 04.jpg  екрани для галереї кейсу
```

## Що змінити перед публікацією

1. **js/config.js** — впишіть свою пошту, нік Telegram, номери WhatsApp/Viber, посилання на Instagram, Behance, LinkedIn, Facebook, TikTok і посилання на кейси на Behance. Вони автоматично з'являться на всіх сторінках.
2. **Ціни** — там само, у `services` (`name` — назва українською, `nameEn` — для англійської версії) (зараз: лендинг від $150, багатосторінковий від $300, магазин від $450, застосунок від $300, редизайн від $150, аудит від $50). Змінюєте число — ціни на всіх картках і в калькуляторі оновлюються самі.
3. **Картинки** — замініть `images/about/portrait.jpg` на своє фото. У папку кожного проєкту додайте `01.jpg`, `02.jpg`, `03.jpg`, `04.jpg` (поки їх немає, на сторінці кейсу видно пунктирну заглушку з підказкою). Назви файлів мають збігатися точно, малими літерами.
4. **Заявки на пошту автоматично (необов'язково)** — зареєструйтесь на formspree.io, створіть форму й вставте її адресу в `formEndpoint`. Без цього кнопка «Надіслати заявку» відкриває поштову програму з готовим листом і пропонує скопіювати текст або відкрити Telegram.

## Мови сайту

Сайт має 6 мов: українська (корінь сайту), англійська `en/`, російська `ru/`, польська `pl/`, німецька `de/`, литовська `lt/`. Перемикач мови — кнопка з кодом мови в шапці (UA ▾): відкриває ту саму сторінку іншою мовою.

- **Тексти** кожної мови — прямо в HTML-файлах її папки. Щоб виправити фразу німецькою, відкрийте потрібний файл у `de/` і змініть текст.
- **Калькулятор і форма** — тексти в `js/main.js` (блок `TEXTS`), назви послуг — у `js/config.js` (поля `nameRu`, `namePl`, `nameDe`, `nameLt` та `unitRu`…).

## Картинки кейсів різними мовами

Основні картинки (українською) лежать як і раніше: `images/projects/<проєкт>/cover.jpg`, `01.jpg` … `04.jpg`.

Щоб на англійській (німецькій, польській…) версії показувалась картинка цією мовою, створіть у папці проєкту підпапку з кодом мови і покладіть туди файли **з тими самими назвами**:

```
images/projects/delintra/
├── cover.jpg  01.jpg  02.jpg  03.jpg  04.jpg      ← українською (як зараз)
├── en/  cover.jpg  01.jpg  02.jpg  03.jpg  04.jpg  ← англійською
├── de/  cover.jpg  01.jpg …                       ← німецькою
├── pl/  …   ru/  …   lt/  …
```

Сайт сам шукає картинку в папці мови. Якщо файла там немає — показує українську. Тому можна додавати переклади поступово: спочатку лише `en/cover.jpg`, потім решту.

Назви папок — тільки малими літерами: `en`, `ru`, `pl`, `de`, `lt`.

## Публікація на GitHub Pages (безкоштовно)

1. Зареєструйтесь на github.com. Нік стане частиною адреси, наприклад `yurochkina`.
2. Натисніть **+ → New repository**. Назва: `yurochkina.github.io` (ваш нік + `.github.io`), тип **Public** → **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file** (або **Add file → Upload files**).
4. Перетягніть **вміст** папки `veexy-portfolio` (саму папку не перетягуйте: `index.html` має лежати в корені, поруч із папками `css`, `js`, `images`, `cases`). Унизу натисніть **Commit changes**.
5. Відкрийте **Settings → Pages**. У розділі *Build and deployment* оберіть *Source: Deploy from a branch*, *Branch: main*, папку `/ (root)` → **Save**.
6. За 1–3 хвилини сайт відкриється за адресою `https://yurochkina.github.io/` (з вашим ніком).

Оновити сайт: знову **Add file → Upload files**, перетягніть змінені файли з тими самими назвами → **Commit changes**.

Якщо назвете репозиторій інакше, наприклад `portfolio`, адреса буде `https://нік.github.io/portfolio/`.

## Як додати посилання на Behance

- **У профілі:** відкрийте свій профіль → **Edit Profile** (редагувати профіль) → у розділі з посиланнями (Web References / Links) додайте адресу сайту. Посилання з'явиться в боковій панелі профілю, і роботодавець зможе ним перейти.
- **У кожному кейсі:** у редакторі проєкту допишіть в опис або в останній блок рядок на зразок «Повна версія портфоліо: https://yurochkina.github.io/».
- **У резюме та LinkedIn:** вставте те саме посилання.

Сайт адаптивний: на телефоні меню згортається в бургер, а картки й калькулятор перебудовуються в одну колонку.
